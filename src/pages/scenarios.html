Scenario questions any unit, often worth 15 marks

Scenario Lab

A scenario question describes a real situation (a printer, a bank, a metro map) and asks which data structure or algorithm to use, and why. Nobody expects code here. They want the right choice and a clear reason. Learn the 4-step method once, then practise on 32 scenarios.

Step 1

The 4-step method

Every scenario answer is the same four moves: operations → data structure → why + complexity → why not the other.

  1. Spot the operations. Underline the verbs in the question: add, remove the oldest, undo the latest, find instantly, connect at least cost, fewest stops.
  2. Name the data structure those operations point to. Use the table below.
  3. Justify it with its key property (LIFO, FIFO, O(1) lookup, balanced height, no cycles) and the time complexity of the main operation.
  4. Reject one alternative in one line (“A queue would undo the oldest change first”). Examiners love this line. Then draw a small diagram.

It is like choosing a container in the kitchen. Soup goes in a bowl, not on a plate. You don’t need to know how the bowl was made. You only need to explain why a bowl suits soup.

Q: An editor needs Undo.
1. Operations: save each change, take back the most recent one.
2. Data structure: stack.
3. Why: undo removes the latest change first, which is LIFO; push and pop are O(1).
4. Why not a queue: it would undo the oldest change first.
Then draw a stack with three changes and an arrow at top.
