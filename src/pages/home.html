How to write an answer that gets full marks

Examiners mark against a checklist. If your answer has every part below, you collect marks even if one detail is wrong. Never leave a question blank: a definition plus a labelled diagram already earns something.

The 8-mark skeleton

  1. Definition in 2–3 lines. Underline the keywords.
  2. Diagram, always, with labels (head, NULL, top, front, rear, root…).
  3. How it works: the algorithm as numbered steps.
  4. Worked example: a small table or a sequence of drawings.
  5. Advantages / disadvantages or a comparison table.
  6. Applications and time complexity.
  7. One-line conclusion.

About 15–18 minutes and 2–3 pages.

The 15-mark skeleton

  1. Same skeleton, but every part is longer.
  2. Introduction + definition + why it is needed.
  3. Types or cases, each with its own diagram.
  4. Algorithm for every operation asked.
  5. A full worked example (every step drawn).
  6. Comparison table, complexity table, applications.
  7. Only if the question says “write a program”: add the code from the optional code box.

About 30–35 minutes and 4–5 pages.

  1. Find the operations the scenario needs (add at the end? remove the latest? look up by key? shortest connections?).
  2. Pick the data structure that does those operations best.
  3. Justify it: “because it gives O(1) insertion at the rear” or “because it is LIFO”.
  4. Draw it for the scenario’s own data, and name one structure you rejected and why.

Practise with 30 of them in the Scenario Lab.

How to use this site

Play first, read second

Every topic has a playground. Press Next to see one step at a time. Each step is one line you would write in the exam.

Predict mode

Switch on Predict mode in any playground. It hides each step until you guess it. This is the fastest way to remember.

Code is optional

You don’t need to code. Programs sit in closed boxes marked “optional” with a C / Java / Python switch, only for “write a program” questions.

Tap I’ve got this after each part, answer the quick checks, and watch your unit rings fill up. Score 80% on a unit challenge to earn its badge.
