Q21 · 8 marks each

Basics, structures, DMA, complexity

Define a data structure. Explain the classification of data structures with examples.

Definition

A data structure is a way of organising and storing data in memory so that it can be accessed and modified efficiently. It defines both how data is arranged and which operations (insert, delete, search, traverse) can be performed on it.

Classification
Data Structures ├── Primitive ── int, float, char, double, pointer └── Non-primitive ├── Linear ──── Array, Linked list, Stack, Queue └── Non-linear ─ Tree, Graph
  1. Primitive: basic types provided by the language, holding a single value. Example: int a = 5;
  2. Non-primitive: derived from primitive types, holding many values.
    • Linear: elements are arranged in a sequence; each has a unique predecessor and successor. Examples: array, linked list, stack, queue.
    • Non-linear: elements are arranged in a hierarchy or network. Examples: tree (hierarchy), graph (network).
Other ways to classify
  • Static vs dynamic: size fixed at compile time (array) vs size changes at run time (linked list).
  • Homogeneous vs heterogeneous: same type of elements (array) vs different types (structure).
Operations on data structures

Traversing, searching, insertion, deletion, sorting and merging.

Abstract Data Type

An ADT specifies the data and the operations without the implementation. Example: Stack ADT = {push, pop, peek, isEmpty}, implementable with an array or a linked list.

Need for data structures

Efficient use of memory, faster search and update, easier handling of large data, and reusability.

Conclusion

Choosing the right data structure decides how fast and how memory-efficient a program is.

What is a structure in C? Explain declaration, initialisation, accessing members, array of structures and pointer to structure with an example.

Definition

A structure is a user-defined data type that groups variables of different data types under a single name. Each variable inside it is a member. It is declared with the keyword struct.

1. Declaration
struct student { int roll; char name[20]; float marks; };

This only creates a template; no memory is allocated until a variable is declared.

2. Declaring variables and initialisation
struct student s1; struct student s2 = {101, "Asha", 88.5};
3. Accessing members (dot operator)
s1.roll = 102; s1.marks = 76.0; printf("%d %.1f", s1.roll, s1.marks);
4. Array of structures

Stores records of many students: struct student cls[60]; The i-th student’s marks are cls[i].marks.

5. Pointer to structure (arrow operator)
struct student *p = &s1; p->marks = 90.0; /* same as (*p).marks */

Define time and space complexity. Explain asymptotic notations with examples.

Definitions

Time complexity is the amount of time an algorithm takes, expressed as the number of basic steps as a function of the input size n. Space complexity is the total memory it needs as a function of n: a fixed part (code, constants, simple variables) plus a variable part (arrays, recursion stack).

Best, average and worst case (linear search)
  • Best: key at first position → 1 comparison → Ω(1).
  • Average: about n/2 comparisons → Θ(n).
  • Worst: key last or absent → n comparisons → O(n).
Asymptotic notations
  1. Big-O (upper bound): f(n) = O(g(n)) if there exist positive constants c and n₀ such that 0 ≤ f(n) ≤ c·g(n) for all n ≥ n₀. Describes the worst case. Example: 3n + 2 = O(n) (take c = 4, n₀ = 2).
  2. Omega (lower bound): f(n) = Ω(g(n)) if f(n) ≥ c·g(n) for all n ≥ n₀. Describes the best case. Example: 3n + 2 = Ω(n) (c = 3).
  3. Theta (tight bound): f(n) = Θ(g(n)) if c₁·g(n) ≤ f(n) ≤ c₂·g(n) for all n ≥ n₀. Example: 3n + 2 = Θ(n).
Common complexities

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

Example of analysis
for i = 1 to n → runs n times for j = 1 to n → runs n times for each i sum = sum + 1 → total n × n = n² ⇒ O(n²)

Linear search: O(n). Binary search: O(log n). Bubble sort: O(n²).

Space complexity example

Summing an array of n elements needs the array (n words) plus a few variables: S(n) = n + 3 → O(n).

Conclusion

Asymptotic analysis compares algorithms independent of the machine, by how they grow for large n.

Linked lists

What is a singly linked list? Write algorithms to insert a node at the beginning, at the end and at a given position.

Definition

A singly linked list is a linear, dynamic data structure made of nodes. Each node has two fields: data and next, the address of the next node. A pointer head points to the first node and the last node’s next is NULL.

struct node { int data; struct node *next; };
Representation
1. Insert at the beginning
  1. Create newNode; newNode→data = x.
  2. newNode→next = head.
  3. head = newNode.

Before: head → 10 → 20 → 30 → NULL. After inserting 5: head → 5 → 10 → 20 → 30 → NULL.

2. Insert at the end
  1. Create newNode; newNode→data = x; newNode→next = NULL.
  2. If head == NULL, head = newNode and stop.
  3. temp = head; while (temp→next ≠ NULL) temp = temp→next.
  4. temp→next = newNode.
3. Insert at position pos
  1. If pos == 1, insert at the beginning and stop.
  2. Create newNode with data x.
  3. temp = head; repeat pos − 2 times: temp = temp→next (if temp becomes NULL, the position is invalid).
  4. newNode→next = temp→next.
  5. temp→next = newNode.

After inserting 15 at position 2 in 10 → 20 → 30.

Write algorithms to delete a node from the beginning, the end and a given position of a singly linked list. Also give algorithms to traverse and search.

1. Delete from the beginning
  1. If head == NULL, print “Underflow” and stop.
  2. temp = head.
  3. head = head→next.
  4. free(temp).
2. Delete from the end
  1. If head == NULL, print “Underflow” and stop.
  2. If head→next == NULL: free(head); head = NULL; stop.
  3. temp = head; while (temp→next→next ≠ NULL) temp = temp→next.
  4. free(temp→next); temp→next = NULL.
3. Delete at position pos
  1. If pos == 1, delete from the beginning.
  2. temp = head; move temp to node pos − 1.
  3. del = temp→next.
  4. temp→next = del→next.
  5. free(del).

After deleting position 2 (20) from 10 → 20 → 30 → 40: node 10 now points to 30.

4. Traversal
  1. temp = head.
  2. While temp ≠ NULL: print temp→data; temp = temp→next.
5. Search for key
  1. temp = head; pos = 1.
  2. While temp ≠ NULL: if temp→data == key, print “found at pos” and stop; else temp = temp→next, pos = pos + 1.
  3. Print “not found”.
Complexity

Delete at beginning O(1); end O(n); position O(n); traversal and search O(n).

Important points

Always handle the empty list and the single-node list; free the deleted node to avoid a memory leak.

Explain a doubly linked list with insertion and deletion operations. What are its advantages over a singly linked list?

Definition

A doubly linked list is a linked list in which every node has three fields: prev (address of the previous node), data, and next (address of the next node). It can be traversed in both directions.

struct node { struct node *prev; int data; struct node *next; };
Insert at the beginning
  1. Create newNode; newNode→prev = NULL; newNode→next = head.
  2. If head ≠ NULL: head→prev = newNode.
  3. head = newNode.
Insert at the end
  1. Create newNode; newNode→next = NULL.
  2. If head == NULL: newNode→prev = NULL; head = newNode; stop.
  3. Move temp to the last node.
  4. temp→next = newNode; newNode→prev = temp.
Insert after a node (position pos)
  1. Move temp to node pos − 1.
  2. newNode→next = temp→next; newNode→prev = temp.
  3. If temp→next ≠ NULL: temp→next→prev = newNode.
  4. temp→next = newNode.
Delete a node (temp)
  1. If temp→prev ≠ NULL: temp→prev→next = temp→next; else head = temp→next.
  2. If temp→next ≠ NULL: temp→next→prev = temp→prev.
  3. free(temp).
Advantages over SLL
  • Traversal in both directions.
  • A node can be deleted using only its own pointer.
  • Inserting before a given node is easy.
Disadvantages
  • Extra memory for the prev pointer.
  • More pointer updates per operation.
Applications

Browser back/forward, undo/redo, music players (next/previous), LRU caches.

What is a circular linked list? Explain insertion and deletion. Compare singly, doubly and circular linked lists.

Definition

A circular linked list is a linked list in which the last node points back to the first node instead of NULL, so the nodes form a circle. Any node can be the starting point.

Traversal
  1. If head == NULL, stop.
  2. temp = head.
  3. Do: print temp→data; temp = temp→next; while (temp ≠ head).
Insert at the end
  1. Create newNode.
  2. If head == NULL: newNode→next = newNode; head = newNode; stop.
  3. Move temp to the last node (temp→next == head).
  4. temp→next = newNode; newNode→next = head.
Insert at the beginning

Same as insert at end, then head = newNode.

Delete from the beginning
  1. If head == NULL: underflow. If head→next == head: free(head), head = NULL.
  2. Move last to the last node.
  3. temp = head; head = head→next; last→next = head.
  4. free(temp).
Delete from the end
  1. Move temp to the second-last node (temp→next→next == head).
  2. free(temp→next); temp→next = head.

Stacks and queues

What is a stack? Explain the push and pop operations using an array, with overflow and underflow conditions. List its applications.

Definition

A stack is a linear data structure in which insertion and deletion take place at only one end, called the top. It follows LIFO (Last In, First Out). Example: a pile of plates.

Operations

push(x) inserts at top, pop() removes from top, peek() returns the top, isEmpty(), isFull(). All are O(1).

Array implementation (stack[MAX], top = −1 initially)

PUSH(x)

  1. If top == MAX − 1: print “Stack Overflow”, stop.
  2. top = top + 1.
  3. stack[top] = x.

POP()

  1. If top == −1: print “Stack Underflow”, stop.
  2. x = stack[top].
  3. top = top − 1; return x.
Overflow and underflow
  • Overflow: push on a full stack (top == MAX − 1).
  • Underflow: pop on an empty stack (top == −1).
Example

push(10), push(20), push(30) → stack = [10, 20, 30], top = 2. pop() returns 30 → top = 1.

Linked list implementation

push = insert at beginning, pop = delete from beginning; head acts as top. No overflow until memory runs out.

Applications

Function calls and recursion, undo, browser back, balanced parentheses, infix to postfix conversion, postfix evaluation, reversing data, backtracking.

What is a queue? What is the drawback of a linear queue? Explain a circular queue with insertion and deletion algorithms and an example.

Queue

A queue is a linear data structure where insertion happens at the rear and deletion at the front. It follows FIFO (First In, First Out). Example: a ticket counter line.

Drawback of a linear queue

In an array queue, rear only moves forward. After some deletions, the slots at the front become empty, but when rear == MAX − 1 the queue reports overflow even though space is free. That space is wasted.

front = 2, rear = 4: “full”, yet slots 0 and 1 are empty.

Circular queue

A circular queue connects the last position back to the first, using (index + 1) % SIZE, so empty slots are reused. Full: (rear + 1) % SIZE == front. Empty: front == −1.

ENQUEUE(x)

  1. If (rear + 1) % SIZE == front: “Overflow”, stop.
  2. If front == −1: front = rear = 0; else rear = (rear + 1) % SIZE.
  3. queue[rear] = x.

DEQUEUE()

  1. If front == −1: “Underflow”, stop.
  2. x = queue[front].
  3. If front == rear: front = rear = −1; else front = (front + 1) % SIZE.
  4. Return x.
Example (SIZE = 5)
Advantages

No wasted space, efficient use of a fixed array, all operations O(1).

Applications

CPU round-robin scheduling, traffic signal systems, keyboard and streaming buffers, printer spooling.

Write an algorithm to check whether the parentheses in an expression are balanced using a stack. Trace it for {[()]} and ([)].

Idea

The last bracket opened must be the first one closed. This is LIFO, so a stack is used.

Algorithm
  1. Initialise an empty stack.
  2. Scan the expression from left to right.
  3. If the symbol is an opening bracket (, [ or {, push it.
  4. If it is a closing bracket: if the stack is empty → not balanced; else pop, and if the popped bracket does not match → not balanced.
  5. After the scan: stack empty → balanced; otherwise → not balanced.
Trace 1: {[()]}
Trace 2: ([)]
Cases of imbalance
  • Mismatched type: ([)]
  • Extra closing bracket: a+b)
  • Unclosed opening bracket: ((a+b)
Complexity

O(n) time, O(n) space for the stack in the worst case. Used by compilers to check syntax.

Write an algorithm to convert an infix expression to postfix using a stack. Convert A + B * (C ^ D − E) ^ (F + G * H) − I.

Notations

Infix: operator between operands (A + B). Prefix: operator before (+ A B). Postfix: operator after (A B +). Postfix needs no brackets and no precedence rules to evaluate, so computers prefer it.

Precedence

^ (highest, right to left) > * / % (left to right) > + − (lowest, left to right).

Algorithm
  1. Scan the infix expression from left to right.
  2. If the symbol is an operand, add it to postfix.
  3. If it is (, push it onto the stack.
  4. If it is ), pop and add to postfix until ( is found; discard both brackets.
  5. If it is an operator: while the stack top is an operator of higher precedence (or equal precedence and the scanned operator is left-associative), pop it to postfix. Then push the scanned operator.
  6. At the end, pop all remaining operators to postfix.
Conversion table
Evaluating a postfix expression
  1. Scan left to right.
  2. Operand → push.
  3. Operator → pop B, pop A, push A op B.
  4. The final value on the stack is the result.

Q24 · 8 marks each

Trees, AVL, B-trees, hashing, spanning trees

Define a tree. Explain tree terminology, types of binary trees and their representation.

Definition

A tree is a non-linear, hierarchical data structure consisting of nodes connected by edges, with one special node called the root; the remaining nodes form disjoint subtrees. A tree with n nodes has n − 1 edges and no cycles.

Terminology (for the tree above)
  • Root: 50. Leaves: 20, 40, 60, 80. Internal nodes: 50, 30, 70.
  • Parent/child: 30 is the parent of 20 and 40. Siblings: 20 and 40.
  • Degree of a node: number of children (degree of 30 = 2).
  • Level/depth: edges from the root (50 at level 0, 30 at level 1). Height of the tree: 2.
  • Ancestors of 40: 30, 50. Subtree: a node with all its descendants.
Binary tree and its types

A binary tree is a tree in which every node has at most two children (left and right).

  • Full/strict: every node has 0 or 2 children.
  • Complete: all levels full except the last, filled from the left.
  • Perfect: all internal nodes have 2 children and all leaves are at the same level.
  • Skewed: every node has only a left (or only a right) child.
Properties

Maximum nodes at level i = 2i; maximum nodes in a tree of height h = 2h+1 − 1; minimum height with n nodes = ⌈log₂(n+1)⌉ − 1.

Representation

Array: root at index 0; children of i at 2i + 1 and 2i + 2; parent at ⌊(i − 1)/2⌋. Efficient for complete trees.

Linked: each node is a structure [left | data | right]; NULL for a missing child. Works for any shape.

Applications

File systems, organisation charts, expression trees, searching (BST), databases (B-trees).

What is a binary search tree? Construct a BST for 45, 15, 79, 90, 10, 55, 12, 20, 50 and write its traversals. Explain deletion.

Definition

A binary search tree is a binary tree in which, for every node, all keys in the left subtree are smaller and all keys in the right subtree are larger than the node’s key.

Construction

Insert each key starting from the root: go left if smaller, right if larger, and attach it at the first empty position.

Traversals
  • Preorder: 45 15 10 12 20 79 55 50 90
  • Inorder: 10 12 15 20 45 50 55 79 90 (sorted)
  • Postorder: 12 10 20 15 50 55 90 79 45
Deletion: three cases
  1. Leaf node (e.g. 20): remove it directly.
  2. One child (e.g. 10, child 12): link 10’s parent directly to 12.
  3. Two children (e.g. 45): replace it with its inorder successor (50, the smallest in the right subtree), then delete the successor.

After deleting 20, 10 and 45.

Complexity

Search, insert, delete: O(h). O(log n) when balanced, O(n) when skewed.

What is an AVL tree? Explain the rotations. Construct an AVL tree for 10, 20, 30, 25, 28, 27.

Definition

An AVL tree is a height-balanced binary search tree in which the balance factor of every node is −1, 0 or +1, where BF = height(left subtree) − height(right subtree). If an insertion makes any BF ±2, the tree is rebalanced by rotations.

Rotations
  • LL (inserted in the left subtree of the left child): single right rotation.
  • RR (right subtree of the right child): single left rotation.
  • LR (right subtree of the left child): left rotation at the child, then right rotation.
  • RL (left subtree of the right child): right rotation at the child, then left rotation.
LL → right rotation
RR → left rotation
Construction of 10, 20, 30, 25, 28, 27

Rotations used: RR at 10 (insert 30), LR at 30 (insert 28), RL at 20 (insert 27). Final level order: 25 20 28 10 27 30.

Advantage

Height stays O(log n), so search, insert and delete are always O(log n), unlike a skewed BST.

What is a B-tree? State its properties and construct a B-tree of order 3 by inserting 10, 20, 30, 40, 50, 60, 70, 80, 90.

Definition

A B-tree of order m is a balanced multi-way search tree in which each node can contain several keys and children, and all leaves are at the same level. It is used for data stored on disk.

Properties
  1. Each node has at most m children and at most m − 1 keys.
  2. Each internal node except the root has at least ⌈m/2⌉ children.
  3. The root has at least 2 children if it is not a leaf.
  4. All leaves are at the same level.
  5. Keys in each node are sorted; a node with k keys has k + 1 children.
Insertion

Insert into the correct leaf in sorted order. If the node overflows (m keys), split it: the median key moves up to the parent and the rest form two nodes. Splits may propagate up to the root, creating a new root.

Construction (order 3: max 2 keys per node)
Applications

Database indexing and file systems: a short, wide tree means very few disk reads. Search, insert and delete are O(log n).

What is hashing? Explain hash functions and collision resolution techniques with an example.

Definition

Hashing is a technique that maps a key directly to a position in a hash table using a hash function h(k), so that search, insertion and deletion take O(1) time on average.

Hash functions
  • Division: h(k) = k mod m (m prime). 72 mod 10 = 2.
  • Mid-square: square k and take the middle digits.
  • Folding: split k into parts and add them (123456 → 123 + 456 = 579).
  • Multiplication: h(k) = ⌊m(kA mod 1)⌋, 0 < A < 1.
Collision

A collision occurs when two keys hash to the same index (72 and 92 both give 2 for m = 10).

Collision resolution techniques
  1. Separate chaining (open hashing): each slot stores a linked list of all keys that hash to it.
  2. Open addressing (closed hashing): find another empty slot by probing:
    • Linear probing: (h(k) + i) mod m
    • Quadratic probing: (h(k) + i²) mod m
    • Double hashing: (h1(k) + i·h2(k)) mod m
Example: 72, 27, 36, 24, 63, 81, 92, 101 with m = 10, linear probing
Same keys with chaining
Load factor and clustering

Load factor α = n/m (here 8/10 = 0.8). Linear probing suffers primary clustering; quadratic probing reduces it but has secondary clustering; double hashing avoids both. When α grows too high, rehash into a larger table.

What is a spanning tree? What is a minimum spanning tree? State the properties and applications.

Definition

A spanning tree of a connected undirected graph G is a subgraph that includes all the vertices of G, is connected, and contains no cycle. It has exactly n − 1 edges for n vertices.

Properties
  • Contains all n vertices and exactly n − 1 edges.
  • Has no cycles; adding one edge creates a cycle.
  • Removing one edge disconnects it (minimally connected).
  • A connected graph can have many spanning trees; a complete graph Kₙ has nn−2 (Cayley’s formula).
Minimum spanning tree

For a weighted graph, the MST is the spanning tree with the minimum total edge weight. It is found using Prim’s or Kruskal’s algorithm.

Applications

Designing networks (cable, telephone, electrical, roads) at minimum cost, network routing without loops, clustering, approximating the travelling salesman problem.

Explain BFS and DFS graph traversals with algorithms and an example. Compare them.

Breadth-first search (BFS)

BFS visits all vertices level by level, visiting all neighbours of a vertex before going deeper. It uses a queue.

  1. Mark start as visited and enqueue it.
  2. While the queue is not empty: dequeue u and print it.
  3. For each unvisited neighbour v of u: mark v visited and enqueue it.
Depth-first search (DFS)

DFS goes as deep as possible along a path before backtracking. It uses a stack (or recursion).

  1. DFS(u): mark u visited and print it.
  2. For each unvisited neighbour v of u: call DFS(v).
  3. When no unvisited neighbour is left, backtrack.

Explain Prim’s algorithm to find a minimum spanning tree with an example.

Introduction

A minimum spanning tree connects all vertices with the minimum total weight. Prim’s algorithm is a greedy algorithm that grows the MST from a starting vertex, one edge at a time.

Algorithm
  1. Select any vertex as the start and include it in the MST.
  2. Among all edges with one end in the MST and the other outside, choose the edge of minimum weight.
  3. Add the edge and its new vertex to the MST.
  4. Repeat until all V vertices are included (V − 1 edges).
Example

MST edges: A–C (2), C–B (1), B–D (5), D–E (3), D–F (6). Minimum cost = 17.

Complexity

O(V²) using an adjacency matrix; O(E log V) using a min-heap. Suitable for dense graphs.

Explain Kruskal’s algorithm with an example. Compare Prim’s and Kruskal’s algorithms.

Introduction

Kruskal’s algorithm is a greedy algorithm that builds the MST by adding edges in increasing order of weight, skipping any edge that would form a cycle.

Algorithm
  1. Sort all edges in increasing order of weight.
  2. Make each vertex a separate set.
  3. For each edge (u, v) in sorted order: if u and v are in different sets, include the edge and merge the sets (union); otherwise reject it (cycle).
  4. Stop when V − 1 edges have been included.
Example (same graph)

Accepted: B–C (1), A–C (2), D–E (3), B–D (5), D–F (6). Rejected: A–B (4), forms the cycle A–B–C. Minimum cost = 17.

3. Node structure

4. Insertion

At beginning: newNode→next = head; head = newNode.

At end: walk temp to the last node; temp→next = newNode; newNode→next = NULL.

At position pos: walk temp to node pos − 1; newNode→next = temp→next; temp→next = newNode.

5. Deletion

From beginning: temp = head; head = head→next; free(temp).

From end: walk temp to the second-last node; free(temp→next); temp→next = NULL.

At position pos: walk temp to node pos − 1; del = temp→next; temp→next = del→next; free(del).

In each case check for an empty list (underflow) first.

temp = head; while temp ≠ NULL: process temp→data; temp = temp→next. For search, compare temp→data with the key at each node.

In a DLL also update prev links (e.g. insert at beginning: head→prev = newNode). In a CLL the last node’s next is head, so loops stop when temp returns to head.

Explain stacks and queues with their implementations and applications. Convert (A + B) * (C − D) to postfix and explain why a circular queue is preferred.

1. Stack

A LIFO structure with insert/delete at the top. Array implementation with top = −1: PUSH checks overflow (top == MAX − 1), increments top and stores; POP checks underflow (top == −1), returns stack[top] and decrements top.

2. Applications of stack

Expression conversion and evaluation, balanced parentheses, recursion, undo, browser back, reversing.

3. Infix to postfix: (A + B) * (C − D)
4. Queue

A FIFO structure: enqueue at the rear, dequeue from the front. Linear array queue: overflow when rear == MAX − 1, underflow when front == −1 or front > rear.

5. Why a circular queue

In a linear queue, slots freed at the front cannot be reused, so the queue reports full while space remains. A circular queue moves rear and front with (i + 1) % SIZE, reusing those slots. Full: (rear + 1) % SIZE == front.

6. Applications of queue

CPU scheduling, printer spooling, BFS, buffers, call centres.

An AVL tree is a self-balancing BST where every node’s balance factor (height of left − height of right subtree) is −1, 0 or +1. A plain BST can become skewed (O(n) search); AVL keeps height O(log n).

RR → left rotation
LR → left then right
RL → right then left

  1. Insert as in a BST.
  2. Update balance factors on the path back to the root.
  3. At the first node with BF ±2, identify the case and rotate.

Delete as in a BST, then move up and rotate wherever BF becomes ±2 (choose the case using the BF of the child).

Search, insert and delete are O(log n). Used where frequent lookups are needed: databases in memory, dictionaries, routing tables.

Explain B-trees. Construct a B-tree of order 5 by inserting C N G A H E K Q M F W L T Z D P R X Y S.

1. Definition

A B-tree of order m is a balanced m-way search tree used for disk-based storage, in which all leaves are on the same level and each node stores multiple sorted keys.

2. Properties (order 5)
  • Maximum 5 children and 4 keys per node.
  • Minimum ⌈5/2⌉ = 3 children (2 keys) for internal non-root nodes.
  • Root has at least 2 children unless it is a leaf.
  • All leaves at the same level; keys sorted within nodes.
3. Insertion procedure

Insert into the proper leaf. When a node reaches 5 keys, split it: the median (3rd key) moves up, and the remaining keys form two nodes of 2 keys each. Splits can propagate to the root.

4. Construction

Final B-tree: root [M]; level 1: [D G] [Q T]; leaves: [A C] [E F] [H K L] [N P] [R S] [W X Y Z].

5. Deletion

Delete from a leaf (swap with predecessor/successor if the key is internal). If a node underflows, borrow from a sibling through the parent, or merge with a sibling.

6. B-tree vs B+ tree

B+ trees keep all data in linked leaves, making range queries faster; internal nodes only guide the search.

7. Applications

Database indexes and file systems; O(log n) search, insert and delete with few disk accesses.
